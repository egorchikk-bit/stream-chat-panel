# Панель стрима

Чат и зрители со всех площадок в одном окне: **Twitch, YouTube, Kick, VK Видео Live**.

- общий чат со смайлами, значками (стример, мод, саб, VIP) и выделенными донатами/подписками;
- зрители по каждому каналу и общая сумма;
- каналы добавляются ссылкой — при первом запуске и в любой момент через ⚙;
- кнопка «Обновить» (клавиша **R**) переподключает чаты, индикатор показывает связь;
- никаких логинов и API-ключей — всё читается анонимно.

## Быстрый старт (Windows)

Скачай [`StreamChatPanel.zip`](../../releases/latest/download/StreamChatPanel.zip) из [Releases](../../releases), распакуй и запусти `ПанельСтрима.exe`.
Откроется окно — вставь ссылки на свои каналы:

```
https://www.twitch.tv/имя_канала
https://www.youtube.com/@канал
https://kick.com/имя_канала
https://live.vkvideo.ru/имя_канала
```

Если Windows пишет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»
(у программы нет платной цифровой подписи).

Настройки хранятся в `%APPDATA%\StreamChat\config.json`. После закрытия окна программа сама выключается через 3 минуты.

## Запуск из исходников

Нужен только Python 3.10+, сторонних библиотек нет.

```bash
python server.py --open
```

Панель откроется на http://localhost:8778 (каналы сохраняются в `config.json` рядом со скриптом).
`Запустить панель.bat` делает то же самое и открывает панель отдельным окном Edge.

Параметры: `--port 8778`, `--config путь\к\config.json`, `--open`, `--idle-exit СЕКУНД`.

Собрать exe: `build.bat` → `dist\ПанельСтрима.exe`.

## Как это устроено

| Площадка | Зрители | Чат |
|---|---|---|
| Twitch | decapi.me | анонимный IRC WebSocket прямо из страницы |
| YouTube | страница `/live` канала | `youtubei/v1/live_chat` |
| Kick | `kick.com/api/v2/channels` | опрос `web.kick.com/api/v1/chat/{id}/history` раз в 2 с |
| VK Видео Live | `api.live.vkvideo.ru/v1/blog/{канал}/public_video_stream` | `…/public_video_stream/chat` |

`server.py` — сервер на стандартной библиотеке Python, `index.html` — вся панель.
Площадки используют неофициальные публичные эндпоинты, поэтому иногда могут что-то поменять у себя.
